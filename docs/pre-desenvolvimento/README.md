# Artefatos Pré-Desenvolvimento — Desafio Monks

Pacote com histórias de usuário, regras de negócio, critérios de aceite, diagramas UML em PlantUML, protótipos de baixa fidelidade, fluxos, rastreabilidade e decisões arquiteturais.

Os artefatos foram derivados do case técnico e do dump de funcionários fornecidos.

## Diagramas
Arquivos `.puml` podem ser renderizados com PlantUML.
* dentro da pasta `imgs` estão as imagens dos diagramas de casos de uso, sequência e modelo de dados.
