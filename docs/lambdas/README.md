## Lambda Documentation Guidelines

When documenting a Lambda:

1. **Trigger** — What invokes this Lambda
2. **Input** — Expected event structure
3. **Output** — What it produces
4. **Permissions** — Required IAM permissions
5. **Timeout/Memory** — Resource configuration
6. **Error Handling** — Retry and dead-letter queue config
7. **Deployment** — How to deploy/update
