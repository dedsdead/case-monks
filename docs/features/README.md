## Feature Documentation Guidelines

When documenting a feature:

1. **User Story** — What the user needs
2. **Acceptance Criteria** — How to verify it works
3. **Implementation Notes** — Technical decisions made
4. **Edge Cases** — Known edge cases and handling
5. **Related Features** — Dependencies and related work
